## Part 1: Server Init Enhancements

### 1.1 CLI Profile Auto-Configuration

**Goal:** When `muxi-server init` runs, automatically configure the CLI (if installed) to connect to this server.

#### Detection

```go
func isCLIInstalled() bool {
    // Check common locations
    locations := []string{
        "muxi",                              // In PATH
        filepath.Join(homeDir, ".local/bin/muxi"),
        "/usr/local/bin/muxi",
    }
    for _, loc := range locations {
        if _, err := exec.LookPath(loc); err == nil {
            return true
        }
    }
    return false
}
```

#### Profile Management

**File:** `~/.muxi/cli/profiles.yaml`

```yaml
version: "1.0"
default: localhost
profiles:
  localhost:
    url: http://localhost:7890
    credentials: "{{copied_from_server_config}}"
    added_at: 2025-01-01T10:00:00Z
    auto_generated: true
  
  # User may have other profiles
  production:
    url: https://muxi.example.com
    credentials: "{{user_configured}}"
    added_at: 2024-12-15T08:00:00Z
```

#### Logic

```go
func updateCLIProfile(creds Credentials) error {
    profilePath := filepath.Join(homeDir, ".muxi", "cli", "profiles.yaml")
    
    var profiles ProfilesConfig
    
    // Load existing profiles if file exists
    if data, err := os.ReadFile(profilePath); err == nil {
        yaml.Unmarshal(data, &profiles)
    } else {
        // Initialize new config
        profiles = ProfilesConfig{
            Version:  "1.0",
            Default:  "localhost",
            Profiles: make(map[string]Profile),
        }
    }
    
    // Create or update localhost profile
    profiles.Profiles["localhost"] = Profile{
        URL:           fmt.Sprintf("http://localhost:%d", serverPort),
        Credentials:   creds,
        AddedAt:       time.Now(),
        AutoGenerated: true,
    }
    
    // Set as default only if no default exists
    if profiles.Default == "" {
        profiles.Default = "localhost"
    }
    
    // Save
    return saveProfiles(profilePath, profiles)
}
```

### 1.2 Service/Daemon Setup

**Goal:** Offer to install MUXI Server as a system service during init.

#### Platform Detection

```go
func detectPlatform() ServicePlatform {
    switch runtime.GOOS {
    case "linux":
        if _, err := exec.LookPath("systemctl"); err == nil {
            return PlatformSystemd
        }
        return PlatformLinuxManual
    case "darwin":
        return PlatformLaunchd
    case "windows":
        return PlatformWindows
    default:
        return PlatformUnsupported
    }
}
```

#### Service Templates

**Linux (systemd):** `/etc/systemd/system/muxi-server.service`
```ini
[Unit]
Description=MUXI Server - Formation Orchestration Platform
After=network.target
Documentation=https://docs.muxi.ai

[Service]
Type=simple
User={{.User}}
Group={{.Group}}
ExecStart={{.BinaryPath}} start
Restart=on-failure
RestartSec=5
StandardOutput=journal
StandardError=journal
Environment=MUXI_LOG_LEVEL=info

[Install]
WantedBy=multi-user.target
```

**macOS (launchd):** `~/Library/LaunchAgents/ai.muxi.server.plist`
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "...">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>ai.muxi.server</string>
    <key>ProgramArguments</key>
    <array>
        <string>{{.BinaryPath}}</string>
        <string>start</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
    <key>StandardOutPath</key>
    <string>{{.LogDir}}/server.log</string>
    <key>StandardErrorPath</key>
    <string>{{.LogDir}}/server.err</string>
</dict>
</plist>
```

#### Installation Commands

| Platform | Install | Enable | Start | Status |
|----------|---------|--------|-------|--------|
| systemd | Write service file | `systemctl enable` | `systemctl start` | `systemctl status` |
| launchd | Write plist | (auto) | `launchctl load` | `launchctl list` |
| Windows | `sc.exe create` | `sc.exe config start=auto` | `sc.exe start` | `sc.exe query` |

#### New CLI Commands

```bash
# Service management
muxi-server service install    # Install as system service
muxi-server service uninstall  # Remove system service
muxi-server service status     # Check service status
muxi-server service logs       # View service logs (journalctl/log file)
```

## Part 2: Server Telemetry

### 2.1 Design Principles

1. **Privacy First** - No PII, no formation content, no secrets
2. **Opt-Out** - Respect `MUXI_TELEMETRY=0` and config setting
3. **Lightweight** - Hourly batches, fire-and-forget, non-blocking
4. **Actionable** - Metrics that inform product decisions

### 2.3 Metrics Explained

#### Server Lifecycle
| Metric | Description | Why It Matters |
|--------|-------------|----------------|
| `uptime_hours` | Hours since server started | Stability indicator |
| `server_starts` | Times server was started this period | Crash detection (high = unstable) |

#### Formation Metrics
| Metric | Description | Why It Matters |
|--------|-------------|----------------|
| `formations.active` | Currently running formations | Scale understanding |
| `formations.total_deployed` | All-time deployments | Adoption metric |
| `formations.total_deleted` | Formations removed | Churn indicator |

#### Deployment Health
| Metric | Description | Why It Matters |
|--------|-------------|----------------|
| `deployments.successful` | Successful deploys | Success rate baseline |
| `deployments.failed` | Failed deploys | Pain point indicator |
| `deployments.updates` | Blue-green updates | Feature adoption |
| `deployments.rollbacks` | Rollbacks performed | Update quality signal |

#### Process Health (Most Insightful!)
| Metric | Description | Why It Matters |
|--------|-------------|----------------|
| `process_health.auto_restarts` | Formations auto-restarted after crash | **Key stability metric** |
| `process_health.crashes` | Formation process crashes | Formation code quality |
| `process_health.health_check_failures` | Health checks that failed | Network/app issues |

#### API Usage
| Metric | Description | Why It Matters |
|--------|-------------|----------------|
| `api_usage.*` | Calls per endpoint | Feature usage patterns |
| Most used endpoints | Shows workflow patterns | UX improvement targets |

#### Proxy Performance
| Metric | Description | Why It Matters |
|--------|-------------|----------------|
| `proxy.requests` | Total proxied requests | Traffic volume |
| `proxy.errors_4xx` | Client errors | Integration issues |
| `proxy.errors_5xx` | Server errors | Formation stability |
| `proxy.avg_latency_ms` | Response time | Performance baseline |

```go

func (s *Server) HandleDeploy(...) {

// In monitor.go

// In proxy.go

    ...

}
```

#### Telemetry Sender

```go
// pkg/telemetry/sender.go

type Sender struct {
    collector  *MetricsCollector
    machineID  string
    country    string
    enabled    bool
    endpoint   string
    interval   time.Duration
}

func (s *Sender) Start(ctx context.Context) {
    if !s.enabled {
        return
    }
    
    ticker := time.NewTicker(s.interval)
    defer ticker.Stop()
    
    for {
        select {
        case <-ctx.Done():
            s.flush() // Final flush on shutdown
            return
        case <-ticker.C:
            s.flush()
        }
    }
}

func (s *Sender) flush() {
    payload := s.collector.Snapshot() // Get and reset counters
    
    go func() {
        ctx, cancel := context.WithTimeout(context.Background(), 2*time.Second)
        defer cancel()
        
        // Fire and forget, max 1 retry
        if err := s.send(ctx, payload); err != nil {
            s.send(ctx, payload) // One retry
        }
    }()
}
```

### 2.5 Opt-Out

```go
func isTelemetryEnabled() bool {
    // Environment variable takes precedence
    if os.Getenv("MUXI_TELEMETRY") == "0" {
        return false
    }
    
    // Check config file
    config, _ := LoadConfig()
    if config.Telemetry != nil && !*config.Telemetry {
        return false
    }
    
    return true // Enabled by default
}
```

**Config file:**
```yaml
# ~/.muxi/server/config.yaml
telemetry: false  # Set to disable telemetry
```

## Part 3: Proxy Header Injection

**Goal:** Pass SDK information to formations for their own telemetry.

When proxying requests to formations, inject headers:

```go
// In proxy.go
func (h *Handler) ServeHTTP(w, r *http.Request) {
    // Mark as server-proxied request
    r.Header.Set("X-Muxi-Server", "1")
    r.Header.Set("X-Muxi-Server-Version", version.Version)
    
    // Forward SDK header if present from client
    // (Client SDKs set X-Muxi-SDK: python/0.1.0)
    
    // Add formation context
    r.Header.Set("X-Muxi-Formation-ID", formationID)
    
    proxy.ServeHTTP(w, r)
}
```
